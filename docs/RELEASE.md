## إجابات نموذج «أمان البيانات» (Data safety)
| السؤال | الإجابة |
|---|---|
| بتجمع بيانات شخصية؟ | نعم: الاسم والبريد (اختياري، للحساب) |
| بيانات مالية؟ | نعم: المعاملات اللي المستخدم بيدخلها بنفسه (مش بيانات كروت) |
| الموقع؟ | لا يُجمع (بيتستخدم على الجهاز بس) |
| مشاركة مع أطراف تالتة؟ | معالجة بس: Anthropic لرد المساعد، وGoogle Firebase للتخزين |
| مشفرة أثناء النقل؟ | نعم (HTTPS) |
| المستخدم يقدر يطلب الحذف؟ | نعم، من جوه التطبيق |
