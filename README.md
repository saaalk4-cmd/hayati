# حياتي 🌿

تطبيق Android عربي (RTL) لتنظيم الحياة اليومية في مكان واحد: العبادات، المهام، العادات، الفلوس، اليوميات، والمناسبات.
وفيه **مساعد ذكي (Claude)** بيرتّب يومك ويضيف مهامك بالكلام العادي.

- التطبيق: Flutter (أندرويد فقط، وضع طولي) + Riverpod + go_router
- السيرفر: Firebase (Auth + Firestore + Cloud Functions)
- المساعد: دالة `askHayati` على Cloud Functions بتكلم Claude API، ومفتاح Claude موجود على السيرفر بس
- الألوان: أخضر زيتوني + ذهبي ([assets/brand/palette.md](assets/brand/palette.md))

## المرحلة 1 ✅

- تسجيل الدخول (جوجل / بريد إلكتروني) + وضع ضيف بيحفظ على الجهاز
- قفل التطبيق برمز PIN + بصمة، وبيتقفل بعد 30 ثانية في الخلفية
- الشاشة الرئيسية «يومي»: التحية، التاريخ الميلادي والهجري، مهام النهارده، آية اليوم
- «مهامي»: إضافة، تعليم كمنتهية، حذف بالسحب
- «مساعد حياتي»: محادثة مع Claude بيقرأ مهامك ويضيف ويعلّم عليها
- وضع نهاري / ليلي / تلقائي
- باقي الأقسام بتعرض «قريبًا إن شاء الله»

## المرحلة 2: عباداتي ✅

- مواقيت الصلاة بتتحسب على الموبايل نفسه حسب موقعك (من غير إنترنت)، وتقدر تختار طريقة الحساب ومذهب العصر
- إشعار الأذان عند دخول وقت كل صلاة، ومجدول للـ 4 أيام الجاية
- الصلاة الجاية وعدّاد تنازلي في «يومي» و«عباداتي»
- متابعة الصلوات (في المسجد، في وقتها، متأخر، فاتتني)
- أذكار الصباح والمساء وبعد الصلاة بعدّاد، وكل ذِكر معاه مصدره
- ورد القرآن: متابعة الختمة بالصفحة والجزء، وهدف يومي
- اتجاه القبلة بالبوصلة
- المساعد بقى يعرف المواقيت، ويسجّل الصلوات وصفحات القرآن

## المرحلة 3: المهام والعادات ✅

- المهام: قوائم (عام، شغل، بيت، مشتريات، دراسة)، معاد، تكرار (يومي، أسبوعي، شهري)، وتذكير بإشعار
- شاشة المهام مقسّمة: متأخرة، النهارده، الجاية، في أي وقت
- العادات: إيموجي، أيام الأسبوع، تذكير، سلسلة الأيام المتتالية (🔥 streak)، آخر 7 أيام، خريطة حرارية لآخر 12 أسبوع، ونسبة الالتزام
- عادات النهارده بتظهر في «يومي» وتعلّم عليها بلمسة
- المساعد بيضيف عادات، ويعلّم عليها، وبيعرف السلاسل، وبيضيف مهام في قوائم ومتكررة

## المرحلة 4: فلوسي ✅

- تسجيل مصروف أو دخل في ثواني: المبلغ، والتصنيف بأيقونة، والتاريخ، وملاحظة
- ملخص الشهر: صرفت كام، الدخل، والميزانية الشهرية وفاضل منها قد إيه (مع تنبيه لو عدّيتها)
- «صرفت على إيه»: توزيع المصروف على التصنيفات بالنسبة
- أهداف ادخار بشريط تقدّم
- مصروف النهارده في الشاشة الرئيسية، بزرار إضافة سريع
- المساعد: «صرفت 150 جنيه أكل»، «أنا صرفت كام الشهر ده؟»، «خلّي ميزانيتي 8000»

## المرحلة 5 والشغل الليلي ✅

- **يومياتي:** المزاج، والكتابة، و«الحمد لله على...»، و«في مثل هذا اليوم»، ومقفولة بالبصمة
- **مناسباتي وأهلي:** أعياد ميلاد ومناسبات بتذكير سنوي، وصلة الرحم وتنبيه «وحشك»
- **إحصائياتي:** ملخص 7 أيام أو 30 يوم، وتقدر تشاركه
- **المساعد أذكى:** «رتّبلي يومي» بيبص على كل بياناتك، وملخص الأسبوع، وبيسمعك بالصوت 🎙️
- **أول مرة:** شاشة بداية وتعريف وسؤال عن الاسم
- **تنبيهات ذكية:** ملخص الصبح، وتذكير صيام الاتنين والخميس والأيام البيض
- **نقل بيانات الضيف** للحساب بعد تسجيل الدخول
- **Play Store:** سياسة الخصوصية، وتصدير البيانات، وحذف الحساب نهائيًا

## الشكل الجديد والخطة 4 ✅

- **«زمرّدي ليلي»:** خلفية زمرّدي غامق بتدرّج ونقشة إسلامية خفيفة، وكروت زجاجية بحواف ذهبي، وشريط سفلي عائم، وحركة واحتفالات. وفيه كمان ثيم «كحلي ملكي» و«رملي دافي»
- **قضاء الصلوات**، و**وضع التركيز (بومودورو)**، و**نسخة احتياطية واسترجاع**
- **إعدادات منظمة** و**حجم الخط**، و«المزيد» بشبكة أقسام
- المساعد عنده 23 أداة

## التحميل

كل رفع على `main` بيشغّل GitHub Actions ويبني APK:
**Actions** ← آخر تشغيل ← **Artifacts** ← `hayati-apk`.

> لو أسرار Firebase مش متضافة في GitHub، الـ APK هيشتغل في **وضع الضيف** بس.
> خطوات ربط Firebase وClaude في [docs/SETUP.md](docs/SETUP.md).

## التشغيل محليًا

```bash
flutter pub get
flutter run --dart-define-from-file=env.json   # env.json فيه إعدادات Firebase (مش بيترفع على GitHub)
```
